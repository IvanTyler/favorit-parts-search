# Поиск автозапчастей и аналогов

Тестовое задание: приложение на React для поиска автозапчастей и аналогов по API
Favorit-Parts («Проценка»).

## Технологии

- React 18 (hooks, без TypeScript)
- Redux Toolkit — два слайса: производители и аналоги
- axios — запросы к API
- Bootstrap 5 + SCSS — вёрстка и тема
- Vite — сборка и прокси к API
- Vitest — тесты

## Как запустить

```bash
npm install
npm run dev      # http://localhost:5173
```

Открыть страницу и ввести артикул, например `01089` или `7160500039S`. Дальше — список
производителей, клик по любому покажет деталь и её аналоги.

Остальное:

```bash
npm run build    # в dist/
npm test         # 10 тестов
npm run lint
```

## Что сделано

- Этап 1: поле артикула, запрос после паузы в вводе, список производителей без дублей.
- Этап 2: клик по производителю — второй запрос с `brand` и `analogues=on`, таблица
  предложений: производитель, артикул, наименование, остаток, цена.
- Цена берётся из складов (`warehouses`), а не из `goods.price`: документация этот реквизит
  использовать запрещает. Показывается минимальная цена среди складов с остатком.
- Состояния загрузки, пустого результата и ошибок API: `Empty key!`, `Invalid key client!`,
  `Request quota exceeded!`, сбой сети.

## Что добавил от себя

- Адаптив: две колонки на десктопе, на мобильном друг под другом, таблица прокручивается.
- Отмена устаревших запросов через `AbortController`, чтобы поздний ответ не перетирал свежий.
- Пока грузится новый бренд, прежняя таблица остаётся под лоадером — страница не прыгает.
- Тесты на нормализацию ответа и оба запроса, включая ошибки.
- Иконка сайта в цвете бренда и заголовок страницы.
