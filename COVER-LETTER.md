## Что в решении

**Два этапа, как в задании.** Вводите артикул → запрос к «Проценке» → список производителей.
Клик по производителю → второй запрос с `brand` и `analogues=on` → таблица предложений
с ценами и остатками.

**Цена считается правильно.** В документации `goods.price` помечен «не использовать, цену брать
из конкретного склада». Поэтому цена берётся из массива `warehouses`: минимальная среди складов,
где есть остаток; если остатка нет нигде — минимальная по складам, а строка помечается
«нет в наличии». Когда подходящих складов несколько, в таблице «от N ₽». Позиции с нулевым
остатком не выбрасываются — документация отдельно говорит, что такая позиция приходит.

**Состояния и ошибки.** `loading / success / error` в Redux Toolkit на каждый этап, лоадеры,
пустые состояния и разбор всех ошибок API: `Empty key!`, `Invalid key client!`,
`Request quota exceeded!`, HTTP-сбой и отсутствие сети. Плюс `AbortController` — если быстро
поменять артикул или бренд, поздний ответ не перезапишет свежий результат.

**Тесты — по делу, а не для покрытия.** 10 тестов: нормализация ответа (цена со склада,
игнор склада без остатка, нулевой остаток, пустой ответ, отсутствие складов) и оба экшена
(запрос, ошибка API, сеть). `npm test` — зелёный, `npm run lint` — без замечаний.

**Вёрстка.** Bootstrap 5 через SCSS с переопределением темы (в красном Favorit-parts),
две колонки на десктопе и стек на мобильном, таблица прокручивается горизонтально,
цены и артикулы не переносятся, после ответа на телефоне блок предложений сам подкручивается
в видимую область. Иконка сайта — фирменная, в цвете бренда.

## Как запустить

```bash
npm install
copy .env.example .env
npm run dev     # http://localhost:5173
```

В `.env` — ключ из примеров документации `VITE_API_KEY=00000000-0000-0000-0000-000000000001`.
Дальше открыть http://localhost:5173 и ввести артикул, например `01089`.

Демо на Vercel: https://favorit-parts-search-black.vercel.app/ — если оно отвечает ошибкой,
значит в настройках проекта не добавлен `VITE_API_KEY` или не передеплоен `vercel.json`
с прокси; подробности в README, раздел «Демо на Vercel». Локально всё поднимается одной командой.
